ABCIFY designed for alphabet image classification using Convolutional Neural Network (CNN), among children aged three to six. It enables children to capture common objects using their smartphones which reinforces children to engage in alphabet learning while at the same time familiarizing items in indoor environments (house and school)—for visual and kinesthetic learning. The web application features a Text-to-Speech function to support auditory learning, improving children’s pronunciation of letters. Additionally, it features an Interactive Quiz to evaluate and assist with children’s Alphabet recognition.
